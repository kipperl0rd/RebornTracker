# RebornTracker
Deck Tracker for TESL REBORN

A barely functional deck tracker, based on the work and source code of extesy/DeckTracker.
The original project hasn't been updated in years, but the foundation and the concept were excellent.
Following the official shutdown of the game and its subsequent successful revival by fans, I took it upon myself—in my own way, and despite my lack of formal expertise—to get the tracker working again and make it compatible with the new REBORN version.
